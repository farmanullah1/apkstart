Install Android to Virtual Disk

The VM window is open. Follow these 6 steps once; afterward ApkStart boots directly from disk without needing the ISO.

  1. Boot Menu: Use ↓ to select Installation - Install Android-x86 to harddisk, press Enter
  2. Choose Partition: Select Create/Modify partitions; when asked about GPT, select No
  3. cfdisk Partition: New → Primary → Press Enter for default size → Bootable → Write → Type yes → Quit
  4. Format: Select vda1 → Choose ext4 when prompted → Yes
  5. Boot & System: Install GRUB: choose Yes; Install /system as read-write: choose Yes
  6. Done: Once progress reaches 100%, click "I have completed installation" below (ApkStart restarts and takes over automatically)

If adb connection fails later: press Ctrl+Alt+F1 in VM window to open terminal, run setprop service.adb.tcp.port 5555、stop adbd、start adbd， then press Ctrl+Alt+F7 to return to GUI.

=======

安装 Android 到虚拟磁盘

虚拟机窗口已打开。按下面 6 步操作一次，之后 ApkStart 会直接从磁盘启动，不再需要镜像。

  1. 启动菜单：用 ↓ 选到 Installation - Install Android-x86 to harddisk，回车
  2. Choose Partition：选 Create/Modify partitions；询问是否使用 GPT 时选 No
  3. cfdisk 分区：New → Primary → 容量直接回车 → Bootable → Write → 输入 yes → Quit
  4. 格式化：选 vda1 → 提示格式化时选 ext4 → Yes
  5. 引导与系统：Install GRUB 选 Yes；Install /system as read-write 选 Yes
  6. 完成：进度到 100% 后点下面的「我已安装完成」（ApkStart 会自动重启并接管）
